# 论文 tailbound 实验

本索引选取论文最后使用的 25 个样例工作流，而不是较早的失败批次或人工给定势函数。
论文 Table 1 保留 24 个样例（Q6 暂不展示），展示时间和 n=50、100 的尾界。
为核对历史实验，机器可读报告仍保留 n=10、50、100。

- [manifest.json](manifest.json)：规范样例名、原运行路径、输入/summary 哈希和原始搜索配置。
- [recorded_bounds.json](recorded_bounds.json)：从保存的候选计算完整界的每个 horizon 最佳值；浮点字段仅供显示，精确参数 A、q 一并保留。
- [ablation.json](ablation.json)：S7/K4 在相同候选池上剔除分支、限定整数指数的结果。
- `validation.json`：本次清理后对全部 25 个工作流重新执行证书复核的结果。

## 查看与复核

在仓库根目录、已安装工具的 Python 环境运行：

```bash
python examples/paper_tailbounds.py report
python examples/paper_tailbounds.py verify --out /tmp/contractive-paper-replay.json
python examples/paper_tailbounds.py verify --cases K4 S7
python examples/paper_tailbounds.py ablate
```

这些命令只读取保存的证书并重新计算/验证，不调用求解器。
`verify` 会从源码重建义务，检查全部候选及原比较结论；不是仅比较摘要哈希。
历史 manifest 的绝对输入路径不存在时，使用新增的、与原哈希一致的 `shared/source.pp`。
`report` / `ablate` 是候选数据报表，证明有效性须结合 `verify` 的结果。

## 分支消融与配置

S7 的直接势函数及 Cauchy 基函数均为一次模板。在 n=20，直接分支约为 3.36e-8，
Cauchy k=7/4 约为 7.05e-10；限定已找到的整数指数后最佳约为 1.46e-9（k=2）。
K4 使用二次直接势函数、一次倒数分母。在 n=20，去掉倒数分支的界约为 0.2054，
加入倒数分支后约为 0.002577（k=1369/256）。这些比较只针对已有候选池。

标准补充实验的正幂/倒数预算为 180/120 秒、次数 2--4；S7 使用一次模板和
120/30 秒预算。S4/S5 采用已保存的二次倒数配置；K6 只选择 wealth 作为模板变量，
但保留完整程序时钟语义。具体以各运行 manifest 为准，不宣称所有样例采用相同预算。

历史目录名称保持不变，以兼容论文工程引用。S4/S5 的输入适配及 S7 的名称映射见
[benchmark 说明](../../contractive_examples/README.md)。pRSM/ExpLinSyn 比较数据和图形
在上级论文仓库；本仓库保留 Contractive 证据与可以独立复核的消融数据。
