# Provenance and scope

Program schemas were independently normalized from the cited paper listings/figures. Authors' source archives were not retrieved; no raw archive files, original solver code, or publisher PDFs are redistributed here. The normalization changes the clock to loop-body executions (except the explicitly marked signed-cost example). See manifest.json for the complete source and transformation map.

The reference implementation and unit tests are new code written for this collection. They are not the authors' implementations. The numerical data are results of that reference code, not experiments on ginfer or the OOPSLA prototype.

Cite the original papers when using their benchmark algorithms. Preserve provenance and timing distinctions when publishing experiments.
